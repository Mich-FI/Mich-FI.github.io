Building a free cloud storage system w/ Raspberry Pi 4

Disclaimer: I did not get the ideas for the implementation of this project by myself. Here is the guide I followed for the entirety of this project: Link to the YouTube video

One day I wondered, as one does, where are my files and data saved when I use a cloud storage service? What is the cloud? I then thought, well it's just someone else's PC! Can I make that myself?
And so I started looking for material to help me build my own cloud storage service!

Overview of the steps

To be able to make this work, I needed the following things:

  • Hardware: a heart to run the system (small pc in my case), a storage device
  • An application for easily transferring files back and forth
  • A way to connect to the system through WAN (Wide Area Network, the Internet C: )
